# Roadmap

1. **Foundation (0.1, done):** GEDCOM reader, tree layouts, CSV org charts, SVG export, web shell.
2. **Editor core (0.2):** canvas with shapes, connectors, selection, undo/redo, pages, stencils, save format.
3. **Org chart suite (0.3):** layout styles (hanging and horizontal done; side-by-side, matrix pending), dotted lines and vacancies (done), assistants, dotted lines, vacancies, roll-ups, photos, XLSX/LDAP import, scenarios.
4. **Family history (0.4):** fan, bowtie and relationship charts, GEDCOM export, privacy filters, citations, multiple-marriage and adoption handling.
5. **Interchange (0.5):** VSDX import/export, PDF and PNG export, printing and poster pages.
6. **Suite integration and platforms (0.6+):** ribbon and command registry shared with the suite, desktop and mobile builds, optional AI.
