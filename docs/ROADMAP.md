# Roadmap

1. **Foundation (0.1, done):** GEDCOM reader, tree layouts, CSV org charts, SVG export, web shell.
2. **Editor core (0.2):** command registry with undo/redo (done), canvas with shapes, connectors, selection, pages, stencils, save format.
3. **Org chart suite (0.3):** layout styles (hanging and horizontal done; side-by-side, matrix pending), dotted lines and vacancies (done), assistants (done), roll-ups (done), XLSX import (done), photos, LDAP import, scenarios.
4. **Family history (0.4):** fan and bowtie charts (done), GEDCOM export, complete or basic (done), privacy filter for living people (done), relationship charts, citations, multiple-marriage and adoption handling.
5. **Interchange (0.5):** PNG export and print/PDF via the browser (done, one page scaled to fit), poster pages for large charts, VSDX import/export.
6. **Suite integration and platforms (0.6+):** ribbon and command registry shared with the suite, desktop and mobile builds, optional AI.
