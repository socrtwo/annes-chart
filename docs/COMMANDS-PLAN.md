# Command plan

Every feature is a command. Each planned command records where the idea comes from. A command is registered only when it works.

| Tab | Commands (examples) | Origin |
|---|---|---|
| File | New from template, Open, Import GEDCOM, Import CSV/XLSX/LDAP, Save, Export SVG/PDF/PNG/VSDX/GEDCOM, Print | Visio, all org chart tools |
| Home | Clipboard, font, shape styles, connector tool, pointer, text tool, align, distribute, group, order | Visio |
| Insert | Shapes, stencils, containers, pictures, hyperlinks, comments | Visio |
| Design | Themes, layout style, spacing, page size, background | Visio, SmartDraw |
| Org Chart | Add subordinate, coworker, manager, assistant; dotted line; vacant position; hanging/side-by-side/matrix layouts; roll-up counts; collapse/expand; scenarios | OrgPlus, Visio Org Chart Wizard, Lucidchart, Org Chart 2.0 |
| Family | Descendants, ancestors, hourglass, fan, bowtie, relationship chart; marriages; privacy filter; citations | GEDCOM tools, Gramps, Family Tree Maker, Legacy |
| Data | Link data, refresh, field mapping, conditional formatting | Visio |
| View | Zoom, rulers, grid, guides, outline, pan and zoom window | Visio |
| Developer | Macros, shape sheet, scripting | Visio |
| AI | Build a chart from a description, tidy a layout, summarize a family line | Anne's Office |
